Help & Info

This QR code generator allows you to create QR codes with different error correction levels and sizes. The input text is limited based on the selected error correction level, which is indicated in the status below the input field. Use the templates for quick generation of common QR code types like URLs, emails, WiFi, etc.

Note: The maximum byte capacity is an approximation and may vary based on the actual content and encoding used in the QR code.

Here are some limits and properties from the library documentation:

  • Data Types: The library supports various data types including numeric, alphanumeric, byte/binary, and kanji characters.
  • Dimension/Size: The size of the QR code can be adjusted (in pixel). Larger sizes may be needed for higher data capacities or error correction levels.
  • Error Correction Levels: L (Low), M (Medium), Q (Quartile), H (High). 
    | Level        | Error resistance |
|--------------|------------------|
| L (Low)      | ~ 7%             |
| M (Medium)   | ~15%             |
| Q (Quartile) | ~25%             |
| H (High)     | ~30%             |
  • Maximum Capacity: Depends on the error correction level and the type of data encoded. Here are the capacity limits for QR Code Version 40 (highest version): 
    Mode     | L    | M    | Q    | H
---------|------|------|------|------
Numeric  | 7089 | 5596 | 3993 | 3057
Alphanum.| 4296 | 3391 | 2420 | 1852
Byte     | 2953 | 2331 | 1663 | 1273
Kanji    | 1817 | 1435 | 1024 |  784
